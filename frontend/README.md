# AnalytiCore Frontend

Interfaz web del sistema AnalytiCore, desarrollada con React y Vite.

## Funcionalidades actuales

- Formulario para ingresar comentarios.
- Validación de longitud.
- Contador de caracteres.
- Vista previa local del texto.
- Diseño adaptable.
- Estructura organizada por capas.

## Ejecución local

```powershell
npm install
npm run dev
